# SAO ZH 模組化翻譯框架 V16（公開測試版）

固定 Agent 只負責啟動、簽章驗證及載入外部執行引擎。Minecraft／SAOUI 專用程式不在核心 JAR 內。

## 三個獨立部分
- SAO_ZH_Agent_v16.jar：固定啟動核心；首次從 V15 更換需完整退出遊戲再啟動一次。
- SAO_ZH_Runtime_1.0.0.jar：外部通用攔截引擎、簽章更新、原子切換、回退、文字投影及有上限的規則語言。
- SAO_ZH_Compatibility_1.0.0.jar：原 V15 已驗證功能的外置相容模組，包括台灣語言選項、TLZH、物品／技能等掛鉤、載入提示及材質包整合。

## 安裝
把安裝包解壓到 Agent 所在目錄（例如 D:\翻譯），保留 SAO_ZH_Extensions 子目錄。
啟動器 JVM 參數只留一條：

    -javaagent:D:\翻譯\SAO_ZH_Agent_v16.jar

不要與 V15 或其他 SAO 翻譯 Agent 同時使用。不需要重新下載已在本機的主材質包。
首次安裝若只放 Agent，會向指定 GitHub 下載已簽章的引擎及相容模組；完整安裝包已附上經驗證快取，較不受首次網路失敗影響。
目前正式支援環境是 Windows、Triggers Client 的 Sword Art Online 實例、Java 21、Minecraft 1.21.4 與已測 SAOUI 2.35.0。

## 不重啟遊戲可以更新什麼
有簽章的 JSON 擴充可新增以前不存在的攔截目標，包括已載入類別的方法回傳值、文字參數、讀取欄位與函式呼叫結果。支援 String 和 Minecraft Text；保留字體樣式、子文字及原資料。
字詞、有限次的字首／字尾／字面替換可熱套用。僅更改譯文的更新不會重新轉換位元碼。

這不是任意 JavaScript／Java 遠端執行器。規則沒有任意檔案、網路、反射或無限迴圈權限；有文字長度、規則數與操作次數限制。
已做的熱更新驗證：同一個 JVM、同一個已開啟的測試介面物件，更新後文字改變，輸入、捲動、選中項目與原始資料不變；真實 Minecraft Text 樣式與子文字也驗證保留。

## 刷新與回退
- saozh-refresh.cmd：要求檢查 GitHub 擴充與重新載入詞庫，不關閉遊戲。
- saozh-rollback.cmd：回退上一份成功的熱規則，並暫停自動更新；再次刷新才恢復更新。
- saozh-disable-rules.cmd：停用新增的熱規則，不移除 V15 相容模組原有功能。
- saozh-status.cmd：查看目前外部規則版本。
本機規則觀察約每 2 秒一次，GitHub 規則約每 60 秒檢查；網路下載與本機觀察分離，不在繪圖回呼做網路／JSON 解析。

## 必須明確區分的限制
本版本將所有 SAO 專用功能搬離固定核心，但原 V15 的功能仍集中在一個外部相容模組，尚未拆成全部獨立可熱卸載的小模組。
新的攔截規則可熱更新；通用引擎／舊相容模組 JAR 更新會自動下載、下次啟動套用，不必手動換核心，但不冒險在同一 JVM 重載已注入的啟動型程式碼。
材質包也維持下次啟動切換，避免 Windows ZIP 鎖檔問題。
對會快取文字或特殊排版的 GUI，仍需要新增相應顯示投影／排版擴充，沒有承諾每一個介面都已會自動重建。程式不會為刷新翻譯而關閉交易、移動物品或發送領獎操作。
本次不是「所有物品、任務、圖鑑都翻譯完」，而是讓後續可以不改固定 Agent 就補上合適的文字攔截與對照。

## 發布擴充
語言及程式： https://github.com/ga200604101111/SAOMCZH
材質包： https://github.com/ga200604101111/SAOMCZHPACK
版本索引： extensions/v1/stable.properties、stable.sig
規則內含唯一 sequence、version、expires。新版本必須增加 sequence；不接受未授權的降版。
維護者用 tools/sign_rules.py 先驗證規則與目標模組方法，再用本機私鑰簽署，可選擇本機立即測試或 git push 發布。私鑰不在安裝包和儲存庫，只有公鑰內建於核心。
直接在 GitHub 改 JSON 而沒有重簽不會生效，這是防止未授權程式進入玩家客戶端的保護。

## 驗證與風險
通過真實 JVM 重轉換測試、錯誤規則/簽章拒絕、遞迴/例外/型別退回、重新啟動後回退、本機觀察自動刷新、原 V15 功能原生離線整合、實際 Minecraft Text 投影。
沒有啟動或重新啟動使用者的 Minecraft，尚未完成實際遊戲畫面驗收。簽章表示受指定維護者核准，不代表程式永遠沒有錯誤；原生 JVM/顯示卡等崩潰不在一般例外回退能保證的範圍。

## 原始碼建置
src 是固定核心/通用引擎；compat-src 是相容模組；tests 是驗證程式。
tools/compile_sources.py --jdk <JDK17以上路徑> --asm <ASM9.10.1.jar> 可從此來源編譯，不需要存取遊戲私有資料。
自行修改程式碼後需要自己的簽章部署流程，不能使用維護者私鑰或冒充已發布的版本。通用建置器不簽署發行檔。
ASM 及 Noto 衍生圖集條款見 licenses。既有遊戲與模組的版權不因本專案而改變。

## 功能模組套件 1.1.0

擴充現在依功能領域維護，一個模組可連接多個介面。7 個模組、38 個已驗證文字攔截點，來源及覆蓋邊界見 [模組說明](../extensions/modules/README.md)。此套件沿用同一個 V16 小核心與 Runtime 1.0.0，不需要重新下載 Agent。

可分別修改共用術語、原生動態翻譯、物品與經濟、任務與追蹤、圖鑑與生物、技能與成長、世界與地點。發布時組合為一致的簽章版本；回退單一模組時，其他模組版本可保持不變。

原 V15 相容功能仍在外部相容 JAR 中並於啟動載入；並非所有底層程式都已獨立熱卸載，也沒有宣稱全部 GUI 的快取排版已解決。

## Runtime 1.1.0 / 模組套件 1.2.0

新增共用文字排版模組（第八個模組），包括依實際字寬處理拍賣行／PassCanvas 中文換行，以及任務日誌與圖鑑的指定文字快取刷新。保留 V16 固定核心、目前 v1.0.5 材質包與原有七個功能模組。
詳見 docs/layout-refresh.md。新外部引擎自動下載後在下次啟動載入，不需換 Agent；載入後相容規則／詞庫仍可熱更新。舊引擎讀 extensions/v1/stable，新引擎讀 extensions/v2/stable。
這不是所有介面與翻譯已完成，也尚未通過真實遊戲圖形驗收。
