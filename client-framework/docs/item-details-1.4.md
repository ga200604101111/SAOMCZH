# 物品詳細規格與批次補譯：規則 1.4.0／詞庫 1.0.6

這是遊戲內的外部翻譯更新，不是修改或重製截圖。V16 Agent、Runtime 1.1.0、原始模組與已使用的材質包都不變。

## 這次定位的入口
目前 SAOUI 的詳細規格使用 `fr.sao.iteminfo.ItemInfoOverlay` 與 `ItemInfoClient$Info`，不同於背包的 ItemTip／TipModel。
新增 Info.name 的回傳顯示翻譯、已快取 Layout.upperName 的讀取翻譯，以及登入獎勵 name／sheetName。後者用受限前綴處理數量，不改獎勵數量或領取操作。
來源與描述在既有 PassCanvas 分行前查譯文；`Sold by Starting Merchant (1 Cols)` 顯示 `販售商人: 起始商人 (1 珂爾)`。商人名稱採本專案用詞，未宣稱官方中文名稱。
只改傳給顯示層的文字，不寫回 Info.name、description、sources、物品 NBT 或伺服器快取，不送操作封包。

## 批次資料
整理 145 個名稱／標籤，及 189 段說明、片段、效果形式；這些包含重用的既有名稱及有限數值範本，不代表相同數量的新增獨立物品。
法文／英文別名只依既有原文與服務端譯文的明確配對擴充。匯入時修正逐字漸層 `§x` 色碼未被清除而使名稱無法配對的問題；只在整理用字串移除色碼，不在遊戲刪除物品顏色。
正式詞庫共 7,559 筆，包含語境、大小寫、空白與雙語別名。先前盤點中的 654 筆待檢查物品文字，目前 470 筆可找到對照，184 筆仍未補齊；這是資料對照統計，不是畫面成功率。
48 筆含百分比／冷卻文字的對照形式被既有嚴格格式驗證器攔下，本輪保留原文，沒有放寬格式驗證。沒有上傳原始捕捉檔、聊天紀錄或私人識別資料。

## 更新與顯示快取
外部規則 1.4.0 為 10 個功能模組、68 個攔截點；可由 V16 熱套用，不需下載新 Agent。本次準備更新時未查到執行中的 V16 遊戲程序，所以本機是候選規則已安裝、尚未確認實機載入。
已經開啟的詳細規格視窗把取得來源存成行陣列；本版不強行變更該靜態物件。關閉再開啟該彈窗會重算來源與分行，無需退出遊戲。名稱的顯示欄位可直接使用新對照。
尚未補齊所有執行期文字收集入口；新增顯示入口不等於已有全面自動缺漏收集。

## 保持原狀的內容
玩家聊天、玩家名稱、國旗及公會代號沒有被翻譯或上傳。本輪沒有新增聊天攔截，更沒有按截圖把玩家的英文發言改成中文。
字型、變白、任務標題省略和圖鑑日期格式不屬於這次已完成的修正。跨文字節點的逐字漸層名稱仍需獨立顯示處理；補齊別名不等於所有富文字片段已能合併翻譯。

## 驗證
舊版先重現詳細規格及相關詞條缺漏；新版通過 13 項資料／規則檢查、68 個掛鉤的當前模組位元碼驗證，以及 24 項真實模組類別／Text 的名稱、價格、樣式、原始資料不變與規則移除測試。
未進行實際遊戲圖形驗收。效能沿用現有有界查表、文字長度及分行快取，不將 GitHub 存取放進繪製執行緒。
