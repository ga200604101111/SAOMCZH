# 共用文字排版與已開介面刷新（Runtime 1.1.0／模組套件 1.2.0）

V16 固定 Agent 不變。新增第八個功能模組 `ui-text-layout`，同一模組涵蓋多個介面，不是每個介面一個插件。

## 本輪修正
- 拍賣行圖四左側說明使用 `PassCanvas.wrap`。原 `wrapNow` 只以空白拆詞，中文長句會被當成一個單字而超框。新的有界分行器呼叫原生 `width(String,float,boolean)` 量測，保留原本 272 設計單位寬度、19 字號、6 行上限。一般任務等使用同一 Canvas 的描述也受益。
- 超過行數上限時在末行顯示省略號；不擅自移動購買按鈕或拉高整個介面。
- 任務日誌的 `rowTexts`、`translated` 與 `descOf`，圖鑑的 `locals`、`refs`、`rowValues`、`catTexts`，在外部規則／詞庫／語言字型環境變化後，於下一次原生繪製入口清除指定文字快取，再由原模組重建。
- 不關閉／重開容器，不送封包，不重設搜尋輸入、選中資料、拖曳物品、捲動位置。重新排版後原模組可能依實際內容高度自行限制合法捲動範圍。
- 回退與停用後保留低成本的清理入口，確保原畫面不殘留舊譯文。這些退役入口不再翻譯，只在版本／語言環境改變時失效指定顯示快取。

## 邊界與效能
每次分行最多 8,192 UTF-16 單位、64 行、2,048 次量測；結果 LRU 最多 128 筆。命中快取時不再次量測。快取鍵包含文字、字體設定、比例、字號、粗體、寬度、行數、語言與更新代次。暫時零寬度／非法尺寸直接沿用原模組結果，不累計成永久停用。
每個介面用弱參照記錄刷新代次，最多 256 個介面。只允許經實際類別驗證的實例 Map 快取或 String 快取鍵；操作限 `clear_map`、`reset_key`，沒有任意方法呼叫／反射腳本。
簽章或欄位型別不符就拒絕整次更新。執行錯誤保留原顯示並限制問題掛鉤；原生 JVM／GPU 記憶體錯誤仍無法由此保證救回。

## 更新相容性
Runtime 1.0.0 不理解新的排版操作，因此 `extensions/v1/stable.properties` 繼續指向原規則 1.1.0；新引擎改讀 `extensions/v2/stable.properties` 的 1.2.0 規則。兩者共享原有七個模組。
外部 Runtime 1.1.0 自動下載後於下次啟動載入，不必重新下載 V16 Agent。使用者本機會預備 pending 引擎；尚未使用 V16 時，首次改用 V16 即可載入。這一引擎載入後，更新此能力範圍內的規則與譯文不需重啟。
材質包維持已公開的 v1.0.5；沒有重建或重新下載 322 MB 主包。

## 驗證與尚未完成

以實際 SAOUI／Minecraft 類別驗證 41 掛鉤及真實任務／圖鑑欄位；原生欄位測試在隔離 JVM 內分配測試物件，沒有啟動遊戲、GL 或伺服器。
