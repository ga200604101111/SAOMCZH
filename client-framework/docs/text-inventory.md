# 可取得文字的批次盤點與缺漏匯出

此工具不是翻譯引擎，也不宣稱抓到整個伺服器全部文字。它把原本分散的已收到語言表、觀察紀錄與本機語言資源合併，避免只有逐一開介面、截圖後才知道有缺漏。

## 收集來源
1. `SAO_TW_Dynamic/raw/*.json`：已由 Agent 保存的 SAOUI LangTable 完整快照。保留原文鍵與伺服器譯文，合併多次快照並標註歷史資料。
2. `review/item_seen.jsonl`、`ui_seen.jsonl`、`daily_seen.jsonl`、`missing_zh_tw.jsonl`：僅接受對應來源清單中的物品、技能、登入獎勵與顯示觀察紀錄。
3. 已安裝模組及已啟用／Agent 正在使用的材質包內 `assets/*/lang/en_us.json`、`fr_fr.json`、`zh_tw.json`。只讀語言 JSON，不複製整個模組、字型或貼圖。
4. 本機詞庫、已驗證雲端快取、本機覆寫及目前啟用規則中的精確對照：用於判斷是否有譯文，不會因有對照就認定畫面正常。

不讀一般聊天日誌、私訊檔、未知 JSON、任意記憶體或網路封包；常見電子郵件、IP、UUID、網址、檔案路徑會排除。自訂物品名仍可能需要人工審核，所有輸出預設只留本機，不自動上傳 GitHub。

## 分類與檔案
- `all_text.jsonl`：整理後的全體文字、原始格式、來源、原文別名、占位符及狀態。
- `missing_text.jsonl`：沒有譯文或仍混合中外文的項目。
- `display_check.jsonl`：已有對照卻需要檢查顯示入口／快取／字型的項目，以及譯文衝突。
- `review_groups.jsonl`：以數字變體等句型分組，只供批次審核，不會把這些模板自動注入遊戲。
- `summary.json`：來源數量、排除原因、限制與警告。

`mapped-needs-display-check` 僅表示找到候選譯文，不是「已在畫面成功翻譯」。大小寫、文字片段、多行拆分、動態條件與 Hook 語境仍可能導致顯示不同。`partial` 保留如「恢復 40 Mana」的半中半英句子，不能像舊匯出器那樣直接捨棄。

## 使用
`py -X utf8 tools/export_inventory.py --root "D:/翻譯"`
可指定 `--game` 指向原遊戲實例，或 `--no-static` 只整理 Agent 已保存的表與紀錄。
輸出位於 `SAO_TW_Dynamic/inventory/inventory-<內容雜湊>/`，`current.json` 指向最近一次完整匯出。相同輸入重跑會重用結果；既有原始紀錄不刪除、不覆寫。匯出中失敗會保留上一份完整輸出。

## 限制
伺服器從未傳給客戶端的內容、未載入的執行期資料、圖片文字，不會憑空出現。此版整合已存在的捕捉能力，沒有新增「任意 Java 渲染函式全部攔截」。原 Agent 的資料快照與指定入口仍各自負責捕捉；此工具負責批次整理。
已讀取來源、未出現的來源、檔案／筆數／容量限制都列在報告中。已知上限：128 份語言快照、512 個本機封裝、每類組合語言資料 128 MiB、150,000 筆整理項目；觸及限制會報告，不宣稱完整。
圖片字形損壞、標題被省略、寬度量測及日期呈現是另一類顯示問題，不因產生缺漏清單就算修好。
