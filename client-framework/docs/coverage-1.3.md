# 功能模組 1.3.0：截圖缺漏與傷害用語

此版本維持固定 Agent V16 與外部 Runtime 1.1.0。規則套件為 10 個功能模組、62 個掛鉤，逐一核對目前安裝的 SAOUI 2.41.2、SAOJob 1.1.3 及 Minecraft 類別；沒有要求玩家換 Agent。

## 修正範圍
- 原動作列的 `⚔ Coup / Hit / 打擊` 改成「單次傷害」，`total` 改成「總傷害」。保留交叉劍、數值、顏色及 DPS；總治療量不會誤改為總傷害。
- 擴充物品名稱、Tooltip 顯示文字、裝備條件及屬性對照。加入目前 SAOUI 的 TipModel / ItemTip 顯示入口，適用符合對照的世界 Boss 物品說明；不修改伺服器物品原資料。
- 補上玩家資訊中的職業、公會成員 rank 與階級選單。玩家姓名、UUID、權限 ID 不修改。
- 擴充任務標題、描述與目標、圖鑑名稱與說明、傳送點及傳送確認；羅盤標題／目標接入相同對照。
- 跨服世界名稱固定為「破碎冥界」，時間函式的 s 顯示為「秒」。只改時間顯示函式，不全域替換字母 s。
- 屬性名稱改回「投射傷害」，其他已確認縮寫如技暴率／技暴傷維持。

## 譯名與內容界線
譯名是本專案對照，不宣稱 Hanaka、Mizunari、Valthac 等音譯是官方中文名。DG／OG 等縮寫沒有可靠全稱時保留縮寫，只翻「區」。世界 Boss 的原開放時間、時區、百分比、價格與排隊數字原樣保留，不擅自換算台灣時間或修改遊戲規則。
詞庫 1.0.4 共 1,940 筆，包含法／英別名、前後空白形式以及多分類對照，不代表 1,940 個獨立物品。未有譯文的內容仍保留原文，不代表全伺服器已翻完。

## 字形資源分開處理
材質包 v1.0.6 把「訓／氾／嶄」從四份 Work Sans MSDF 字形索引移除，讓原模組使用既有完整 Noto CJK 備援。字型二進位和全部字形圖片不變；此為針對畫面異常的備援處理，不能僅憑字集包含該字就宣稱實機字形已修好。
材質包另修正投射傷害、傷害動作列用詞與破碎冥界別名。遊戲中不覆寫已開啟的 ZIP，也不自動 F3+T；下載驗證後等下次正常啟動切換。

## 驗證
先用舊規則重現 15 組截圖對照失敗，再以新版通過；另有 5 項字形包檢查。以真實 SAOUI 類別測試動作列、Tooltip 名稱與格擋耐久、數字與文字顏色、來源不變及回退（14 個檢查）。
本機正在執行的 V16 客戶端曾回報 `version=1.3.0 sequence=103 hooks=62`，確認規則熱套用成功，並非僅下載了檔案。這不等於所有介面均完成視覺驗收。
